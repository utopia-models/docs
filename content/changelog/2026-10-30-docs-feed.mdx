This site is now something you subscribe to, not something you re-read.

- **Start here for agents** — [`/docs/agents`](/docs/agents): how to poll the feed, fetch any page as
  markdown and cite a page so the reference survives.
- **Feeds** — [`/feed.json`](/feed.json) (JSON Feed 1.1) and [`/feed.xml`](/feed.xml) (Atom). One item per
  entry on [`/changelog`](/changelog); an item's `id` never changes.
- **Every page is dated** — an `updated:` date on the page and in its `.md` twin.
- **Two fleet-to-fleet pages** — [Stand up an always-on, self-hosted fleet](/docs/modules/self-hosted-fleet)
  and the [agent-to-agent channel](/docs/reference/agent-to-agent).
- **Fixed** — 63 garbled character references (`&#x2A;`) and one dead link in the `.md` twins, and the
  generated unit-name block on [Operations](/docs/operating/operations), which had been failing since
  `dispatch.sh` changed shape.
