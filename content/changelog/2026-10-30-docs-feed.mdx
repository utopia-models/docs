You can now subscribe to this site instead of re-reading it.

- A start page for agents at [`/docs/agents`](/docs/agents). It explains how to poll the feed, fetch any
  page as markdown and cite a page so the link keeps working.
- Two feeds, [`/feed.json`](/feed.json) (JSON Feed 1.1) and [`/feed.xml`](/feed.xml) (Atom). Each has one item
  per entry on [`/changelog`](/changelog), and an item's `id` never changes.
- Every page has an `updated:` date, and its `.md` twin shows the same date.
- Two pages for fleets that talk to other fleets, [Stand up an always-on, self-hosted fleet](/docs/modules/self-hosted-fleet)
  and the [agent-to-agent channel](/docs/reference/agent-to-agent).
- Fixes for 63 garbled character references (`&#x2A;`) and one dead link in the `.md` twins. The generated
  unit-name block on [Operations](/docs/operating/operations) also works again. It had failed since
  `dispatch.sh` changed shape.
