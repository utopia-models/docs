The source of this site is now public at [github.com/utopia-models/docs](https://github.com/utopia-models/docs).

- The repo holds the Fumadocs app, every page under `content/docs/`, the feeds and the `.md` twins. The
  GitHub icon in the nav now links to it.
- It is a new repo because I seeded it from the current tree of the old private repo, without history. That
  history held personal data that the current pages do not, and a fresh repo publishes none of it.
- Only the allowlisted pipeline in the knowledge base writes to `content/docs/source/`, as before. It scans
  every file for secrets and personal data before publishing it.
