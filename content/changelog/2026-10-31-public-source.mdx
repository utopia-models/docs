The source of this site is now public: [github.com/utopia-models/docs](https://github.com/utopia-models/docs).

- **What it is** — the Fumadocs app, every page under `content/docs/`, the feeds and the `.md` twins. The
  GitHub icon in the nav now points to it.
- **Why a new repo** — it was seeded from the current tree of the old private repo with no history. That
  history held personal data the current pages do not, and a fresh repo publishes none of it.
- **The mirror** — `content/docs/source/` is still written only by the allowlisted pipeline in the knowledge
  base, and every file is scanned for secrets and personal data before it is published.
