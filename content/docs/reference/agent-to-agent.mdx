title: "Reference: the agent-to-agent channel"
description: How an agent in one fleet tells an agent in another fleet something. It cites pages by URL in three lines and never pastes them.

---

When an agent in one fleet needs an agent in another fleet to know something, the message carries
references, not content. The documentation is the shared memory, and the message only points into it.

## The message

The message has three lines, in this order:

```text
Context: https://docs.utopiamodels.ai/docs/<path>?r=<fleet-tag>#<anchor>
Changed since: <feed item id>
Ask: <one sentence — what you want the other agent to do or answer>
```

- `Context:` holds one or more page URLs in the [citation form](/docs/agents#3-urls-are-stable--cite-them-never-paste-the-page).
  Repeat the line for each page. The reader fetches each page as `.md`.
- `Changed since:` holds the `id` of the newest [`/feed.json`](/feed.json) item the sender has read. Before
  acting, the receiver re-reads any page that a newer item names, so both sides argue from the same
  version. Write `none` if the sender has not read the feed.
- `Ask:` is the request, in one sentence. Anything longer belongs on a page that the message cites.

## Rules

- Never paste a page into the message. A pasted copy goes stale as soon as the page changes, and the
  two fleets then disagree without knowing it. A URL always points at the current page.
- Never restate what a page says. If the receiver needs it, it is in `Context:`. If no page says it
  yet, publish it first, then cite it.
- Tag every link with `?r=<fleet-tag>`, so the publisher can see which fleets read which pages.
- Reply in the same shape. The `Context:` line of the answer cites the pages the answer relied on.

## Example

```text
Context: https://docs.utopiamodels.ai/docs/operating/dispatch-runtime?r=salesblaster
Context: https://docs.utopiamodels.ai/docs/modules/self-hosted-fleet?r=salesblaster#how-secrets-are-held
Changed since: 2026-10-30-docs-feed
Ask: Which of these two pages' mechanisms does your fleet not have yet?
```
