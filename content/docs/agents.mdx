You are an agent, and someone handed you `docs.utopiamodels.ai`. This page is the whole contract between
this site and you. It is short on purpose: read it once, then follow the four rules.

## 1. Read markdown, not HTML

Every page is served as raw markdown at its own path with `.md` appended. Fetch that, never the HTML:

```bash
curl -s https://docs.utopiamodels.ai/docs/agents.md          # this page
curl -s https://docs.utopiamodels.ai/docs/structure/architecture.md
curl -s https://docs.utopiamodels.ai/llms.txt                 # the index of every page
```

The first lines of every `.md` twin are its title, its URL and `Updated: YYYY-MM-DD` — the date the page
last changed. If your cached copy is older than that date, re-fetch it.

## 2. Stay current by polling the feed, by item id

[`/feed.json`](/feed.json) is a [JSON Feed 1.1](https://jsonfeed.org/version/1.1) listing every change to
this site, newest first. [`/feed.xml`](/feed.xml) is the same items as Atom, and [`/changelog`](/changelog)
is the same items as a page.

- Each item's `id` (for example `2026-10-30-docs-feed`) is **permanent**. Store the newest `id` you have
  processed; on the next poll, every item above it in `items` is new to you.
- Each item's `tags` are the paths it changed. Re-fetch those as `.md`; nothing else needs re-reading.
- Poll as often as you like — the feed is a static file with no rate limit. Once a day is plenty.

```bash
curl -s https://docs.utopiamodels.ai/feed.json | jq -r '.items[] | "\(.id)\t\(.tags | join(" "))"'
```

## 3. URLs are stable — cite them, never paste the page

A published path does not change. When a page moves, its old URL answers `308` to the new one (the
`.md` twin too), so a link you stored keeps working. That makes a URL the right thing to hand another
agent: **cite a page, never paste its contents** — the page will have moved on by the time a pasted
copy is read.

The citation form is

```text
https://docs.utopiamodels.ai/docs/<path>?r=<fleet-tag>#<anchor>
```

- `#<anchor>` is the heading id (the `[#id]` suffix on each heading in the `.md` twin). It goes
  **last**: anything after `#` never reaches the server, so a tag written after the anchor is lost.
- `?r=<fleet-tag>` is a short lowercase tag naming your fleet or the recipient (`?r=salesblaster`). It
  changes nothing about what is served; it lets us see which fleets read which pages. Letters, digits
  and `-`, up to 32 characters.

How to send a citation to another agent: [the agent-to-agent channel](/docs/reference/agent-to-agent).

## 4. Everything in one request

[`/llms-full.txt`](/llms-full.txt) is every page as markdown, concatenated. Use it when you want the
whole picture once; use the feed afterwards to keep it current.
